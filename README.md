# CM Infrastructure Project Monitor (POC)

Verification layer for government infrastructure projects in **Rajasthan** and **Maharashtra**:
every project has a site, dated satellite / drone / field imagery, progress history, issues and directives.
See [PROJECT_BRIEF.md](PROJECT_BRIEF.md) for the full scope.

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind v4 · shadcn/ui (Base UI) · Prisma 7 + SQLite (`better-sqlite3` adapter)

## Getting started

```bash
npm install            # also runs `prisma generate`
cp .env.example .env   # DATABASE_URL="file:./dev.db"
npm run db:migrate     # create / update the SQLite database
npm run db:seed        # demo data + placeholder imagery
npm run dev            # http://localhost:3000
```

> npm 11 blocks dependency install scripts unless approved. The ones this project needs
> (`better-sqlite3`, `prisma`, `@prisma/engines`, `esbuild`, `unrs-resolver`) are already listed
> under `allowScripts` in `package.json`.

Useful scripts:

| Script | What it does |
|---|---|
| `npm run db:seed` | Wipes and re-seeds all data (safe to re-run) |
| `npm run db:reset` | Drops the DB, re-applies migrations and re-seeds |
| `npm run db:studio` | Opens Prisma Studio to browse the data |

## Demo data

- **Districts:** Rajasthan 41 (post Dec-2024 reorganisation), Maharashtra 36 — all seeded with English + local names.
- **Departments (per state):** PWD, Metro, Drainage & Sewer, Urban, Roads & Buildings, Rural, MGNREGA.
- **Projects:** 64 across Jaipur, Jodhpur, Udaipur, Kota, Mumbai Suburban, Pune, Nagpur and Nashik,
  with a mix of On-Going / Completed / Delayed / Stalled / Not Started.
- Each project has monthly progress updates, 2–4 dated imagery captures, and (for delayed/stalled ones)
  pending issues tagged to the last review meeting. CMO directives exist per state, some overdue.
- Seed data lives in `prisma/seed-data/` — edit those files to change names, budgets or statuses.

## Manual setup

### 1. District boundary GeoJSON (needed for the map screen, build step 3)

Put two files in `public/geo/`:

- `public/geo/rajasthan-districts.geojson`
- `public/geo/maharashtra-districts.geojson`

Each district feature must have a **`geo_code`** property equal to the district's code in
`prisma/seed-data/districts.ts` (e.g. `RJ-JAIPUR`, `MH-CHHATRAPATI-SAMBHAJINAGAR`). The property name
can be changed per state via `geoCodeProperty` in `config/states.ts`.

Where to get them:

- **Maharashtra:** most open-data sources (e.g. DataMeet's India district maps, GADM) have all 36 districts,
  sometimes under old names (Ahmednagar, Aurangabad, Osmanabad) — the `aliases` in `districts.ts` list these.
- **Rajasthan:** most free files still show the **old 33 districts**. The current 41 add Balotra, Beawar,
  Deeg, Didwana-Kuchaman, Khairthal-Tijara, Kotputli-Behror, Phalodi and Salumbar. Options:
  1. Ask the client / Rajasthan GIS cell (or Bhuvan) for the official 41-district boundaries, or
  2. For the demo, use a 33-district file — the 8 new districts will simply have no shape on the map.

To add `geo_code` to a downloaded file, open it in <https://mapshaper.org>, then use the console, e.g.
`-each 'geo_code = "RJ-" + district.toUpperCase().replace(/ /g, "-")'` and fix any mismatches by hand.

### 2. Real before/after imagery (optional, recommended for the demo)

The seed generates stylised placeholder images (marked "DEMO IMAGERY") so the comparison screen works
out of the box. For a convincing demo, take screenshots of the same real construction site on two dates
from Google Earth Pro (historical imagery slider) or Esri Wayback, and either:

- upload them through the app's upload screen (build step 6), or
- overwrite files in `public/uploads/demo/` (e.g. `building-s0-v0.jpg` = empty site, `building-s4-v0.jpg` = finished) — note
  re-running the seed regenerates these.

> Free imagery (Sentinel-2, ISRO Bhuvan) is ~10 m resolution — not enough to see individual buildings.
> Building-level verification in production needs paid high-resolution imagery or drone uploads.
